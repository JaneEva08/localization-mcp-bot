# Текст для сдачи VPf08

Репозиторий: https://github.com/JaneEva08/localization-mcp-bot

Я адаптировала MCP-проект под рабочую задачу QA игровой локализации. Бот импортирует данные из Excel в локальную SQLite и позволяет найти китайский оригинал по русскому переводу, перевод по оригиналу, код предмета по названию или описанию и название с описанием по коду. В ответе показывает исходные атрибуты и номер строки Excel. Если способ поиска предмета не указан, бот задаёт уточняющий вопрос.

Сервер предоставляет четыре MCP-инструмента через HTTP. Telegram-бот получает их описания динамически; модель выбирает инструмент для обычной фразы, а приложение выводит найденные значения без перефразирования. Проверила основные сценарии в Telegram на локальной базе из 699 154 записей; также прошли 20 автоматических тестов. В репозитории есть код, инструкция запуска, генератор вымышленных демоданных, подробный HOMEWORK.md и скриншоты проверки. Рабочая база и ключи в репозиторий не включены.
